# Privacy policy: JobSearch Pal

*Edit, then publish at a public URL (required by the Chrome Web Store if you handle user data).*

JobSearch Pal ⟨does not collect, store remotely, sell or share any personal data⟩. ⟨Describe any data kept
on your device, e.g. settings saved in Chrome's extension storage, and how to delete it: remove the
extension.⟩

- Permissions used, only for the features described in the store listing:
  - activeTab and scripting: read the job post on the current tab, only when you click the toolbar icon.
  - storage: keep your saved jobs and settings on this device.
  - sidePanel: show your saved jobs in Chrome's side panel.
  - alarms: schedule the follow-up reminders you set.
  - notifications: show those reminders as Chrome notifications.
- No host permissions and no content scripts: the extension cannot read any site in the background.
