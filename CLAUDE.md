# JobSearch Pal

Save job posts from the page you're on, track each application's status, set reminders, back up and export. Free and local-only.
Manifest V3 Chrome extension (TypeScript, esbuild, Vitest, ESLint). Generated by chrome-extension-factory
0.4.0 with modules: e2e-playwright, page-inject, storage. This repository is independent: work only inside it.

## Start of every session
1. Read the "Current state" block at the top of `docs/PROGRESS.md`. It says what's next.
2. Find code with `docs/REPO-MAP.md`; read only the files the task names. Don't scan the whole repo.
3. Detailed procedures are in the skills: `/plan-feature`, `/implement-task`, `/verify-extension`,
   `/prepare-release`. Rules for each module load automatically from `.claude/rules/` when you open its files.

## Commands
| Task | Command |
|---|---|
| Full gate (run before reporting any task done) | `npm run verify` |
| Build to `dist/` / watch build | `npm run build` / `npm run dev` |
| Typecheck · lint · unit tests | `npm run typecheck` · `npm run lint` · `npm test` |

## Hard rules
1. **Permissions** are exactly [activeTab, scripting, storage] (`extension.config.json`, enforced by `scripts/check-dist.ts`).
2. **No HTML sinks** (`innerHTML`, `outerHTML`, `insertAdjacentHTML`, `document.write`, `DOMParser`):
   use `createElement` + `textContent`. Never weaken `eslint.config.js`, tests or `scripts/check-dist.ts`.
3. **No remote code:** no eval, `new Function`, CDN scripts or remote imports. Bundle everything.
4. **Validate everything read back** (storage, messages, files) before use.
5. **Messages** go through `src/background/router.ts` with a validator and a sender check.
6. **The owner approves first:** new permissions or host access, new or paid dependencies, accounts,
   servers or analytics, architecture changes, `git push`/merge to main/tags/history rewrites, and any
   publishing. Ask, record the decision in `docs/DECISIONS.md`, then act.

## Product rules
Full text: `.claude/rules/product.md` (loads for `src/**`). Decisions: `docs/DECISIONS.md` ADR-002 onward.
- **X1–X11** extension rules: no network, no remote code, nothing on LinkedIn/Indeed/Glassdoor,
  read only on user action, never submit, no special category data, no invented experience,
  explained scores, export/delete/encrypted backup, minimum permissions, ULIDs + event log as truth.
- **P1–P12** platform rules that apply here: no auto-apply, privacy, WCAG 2.2 AA, secure defaults,
  no personal data in logs.
- `src/core` uses no `chrome`, `window` or `document`. Phases 0–4 = the sources' E0–E4; work is milestones M0, M1, …

## Workflow
Brief (`docs/PRODUCT_BRIEF.md`) → `/plan-feature` → owner approves → `/implement-task` (one task, one
commit) → `/verify-extension` → manual checks in `docs/QA.md` → `/prepare-release <version>`.
End every session by updating the "Current state" block in `docs/PROGRESS.md`.
