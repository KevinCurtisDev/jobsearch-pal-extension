# JobSearch Pal

Save job posts from the page you're on, track each application's status, set reminders, back up and export. Free and local-only.

A Manifest V3 Chrome extension. Permissions: activeTab, scripting, storage.

## Setup (Ubuntu / WSL)

```bash
bash scripts/setup.sh        # npm install, git init + hooks, npm run verify
```

## Commands

| Task | Command |
|---|---|
| Full quality gate | `npm run verify` |
| Production build to `dist/` | `npm run build` |
| Watch build (dev, `(dev)` suffix in the name) | `npm run dev` |
| Typecheck / lint / unit tests | `npm run typecheck` / `npm run lint` / `npm test` |
| E2E tests in Chromium (builds first; `HEADLESS=0` to watch) | `npm run test:e2e` |
| Chrome Web Store zip (`release/jobsearch-pal-<version>.zip`) | `npm run package` |
| Instruction size report | `npm run measure` |

## Load it in Chrome (Windows, with the project in WSL)

1. `npm run build`
2. Open `chrome://extensions`, turn on **Developer mode**, click **Load unpacked**.
3. Choose `\\wsl.localhost\Ubuntu\<project path>\dist` (run `pwd` in the project to see the path).
4. After each rebuild, click the reload icon on the extension's card.

## Modules

- **core** 1.0.0: Manifest V3 skeleton: service worker with a validated message router, strict CSP, TypeScript, esbuild, ESLint security rules, Vitest, dist/ gate and deterministic store zip. No permissions.
- **e2e-playwright** 1.0.0: Playwright end-to-end tests in real Chromium: loads the built extension, clicks the toolbar action, drives the real popup and reads extension state.
- **page-inject** 1.0.0: Runs a script in the current page on demand (activeTab + scripting): toolbar click or popup button, one instance per tab, clear reasons on pages Chrome blocks.
- **storage** 1.0.0: Typed, validated chrome.storage keys (local, sync, session) with fallbacks, a sync-size guard and change watching.
